## Oroya Video 0.6.1

Versión de estabilidad: la instalación y la actualización del runtime de IA ya no pueden dejarlo roto.

### Runtime de IA
- **Corregido:** al pulsar *Actualizar componentes de IA* o *Instalar runtime de IA* con la app abierta, la instalación fallaba con "Acceso denegado" (`PermissionError: [WinError 5]`). Además, el runtime quedaba roto: PyTorch dejaba de estar disponible y cada reintento fallaba igual.
- **Instalación aislada:**
  - El runtime nuevo se instala en una carpeta aparte y se comprueba en otro proceso.
  - Al terminar, el motor se reinicia solo para activarlo.
  - Si algo falla a mitad, el runtime anterior sigue funcionando.
- **Reparación:** si tu runtime quedó roto por este fallo, pulsa **Instalar runtime de IA** en *Setup* y se reconstruye limpio. Las descargas salen de la caché, así que tarda pocos minutos.
- Versiones fijadas para todos los paquetes, sin duplicados mezclados.
- La instalación muestra su progreso también al actualizar componentes.
- Un doble clic ya no inicia dos instalaciones.

### Otros arreglos
- **Reintentar** un trabajo ya no falla si un archivo temporal sigue abierto un instante, por ejemplo una vista previa o el antivirus.
- Los registros del motor usan siempre UTF-8. Antes, con Windows configurado en algunos idiomas (como japonés), un mensaje con tildes rompía el registro.

---

### English summary
- **AI runtime install fixed:** updating or installing it with the app open failed with "Access denied" and left PyTorch broken.
  - Installs now go to a separate folder, are verified in another process, and are activated by restarting the engine automatically.
  - A failed install never breaks the working runtime.
  - *Setup → Install AI runtime* repairs a broken runtime.
  - All packages are pinned.
- **Other fixes:**
  - *Retry* tolerates temporarily locked temp files.
  - Engine logs are always UTF-8.
