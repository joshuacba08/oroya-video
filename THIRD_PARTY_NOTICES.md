a pinned SHA-256 (`backend/app/services/model_download_service.py`).

not always stated; if you plan commercial use, review each source yourself.

### GFPGAN (face restoration): non-commercial use only

GFPGAN's code is licensed under Apache-2.0 "except for the third-party components" listed in its
LICENSE, some of which are under non-commercial terms (NVIDIA Source Code License for StyleGAN2,
CC BY-NC-SA 4.0 for DFDNet). Its weights were trained on FFHQ, a dataset published under
CC BY-NC-SA 4.0, and the facexlib face parsing weights on CelebAMask-HQ, which is limited to
non-commercial research. Because of this, Oroya Video treats GFPGAN and its helper weights as
**non-commercial use only**: the app shows this in the Models page and asks the user to accept it
before downloading them. Face restoration is optional; every other feature works without it.

## Tools

FFmpeg is not bundled. Setup downloads the Windows build from
[GyanD/codexffmpeg](https://github.com/GyanD/codexffmpeg) (or uses one already installed) and runs
it as a separate program; Oroya Video does not link to it. Those builds are licensed under the
GPL v3 because they include GPL components such as x264 and x265; see https://ffmpeg.org/legal.html
and https://www.gyan.dev/ffmpeg/builds/ for the license and the source code.

Some video formats (for example H.264, H.265 and AAC) may be covered by patents in some
countries. Users are responsible for complying with the rules that apply where they use them.
